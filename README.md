# Banking System

Консольное банковское приложение на C# (.NET 10).

## Возможности
- Расчётные и накопительные счета с полиморфным поведением
- Переводы между счетами с валидацией (сумма > 0, счёт существует, достаточно средств)
- Собственная иерархия исключений (AccountNotFoundException, InsufficientFundsException)
- Сохранение и загрузка банка в JSON с полиморфной десериализацией
- LINQ-отчёты: топ счетов, средний баланс, группировка по типам

## Технологии
- C# 12 / .NET 10
- System.Text.Json (полиморфная сериализация через JsonDerivedType)
- LINQ, generics, records

## Запуск
dotnet run --project src/BankingSystem

## Чему научил проект
- Инкапсуляция: объект отдаёт услуги, а не данные (SaveToJson вместо доступа к словарю)
- Исключения vs Try-паттерн: когда какое API уместно
- Эволюция формата данных: JSON переживает добавление полей, позиционный формат — нет
